# 02 · 四大类特征计算规则表

> 第一步「研究与总结」核心产出。本文件是 `src/modules/*/rules.ts` 的实现依据。
> 每条规则格式：**度量 (metric) → 归一化 → 分级 (band) → 传统术语 (classicalTerm) → 出处**

---

## 零、通用约定

### 0.1 归一化基准

所有长度必须除以一个**尺度不变量**，否则会随拍摄距离变化：

| 模块 | 归一化基准 | 符号 |
|---|---|---|
| 面相 | 双眼外眦距离 `dist(33, 263)` | `IOD` |
| 骨相（面部） | 同上 | `IOD` |
| 手相 | 掌宽 `dist(5, 17)`（透视归一化后固定 = 256px） | `PW` |
| 体相 / 骨相（体） | 优先用 `worldLandmarks`（单位：米，原点在髋中心）；退化时用肩宽 `dist(11,12)` | `SW` |

> `PoseLandmarker` 的 `worldLandmarks` 输出真实米制坐标，与相机距离无关——**体相所有比例一律用它算**，不要用归一化图像坐标。

### 0.2 五级分档（band）

所有连续量统一映射为 5 档，便于挂接传统术语：

| band | 含义 | 记法 |
|---|---|---|
| `very_low` | 显著偏低 | −− |
| `low` | 偏低 | − |
| `balanced` | 中和 / 匀称 | ○ |
| `high` | 偏高 | + |
| `very_high` | 显著偏高 | ++ |

分档阈值以「中和区间」为中心定义，写作 `[a, b]` 表示落在此区间为 `balanced`。默认取**东亚成年人常见范围**，全部集中在 `src/modules/<type>/thresholds.ts`，可调。

> ⚠️ **阈值来源说明（已被实测修正一轮，2026-08-01）**
>
> 本文初稿的阈值是按传统相术的**理想值**猜的（「五眼」就取 5.0、「三停均分」就取 1/3）。
> 实测发现这套猜测偏差很大，会造成**系统性误判**——按初稿阈值，几乎每个人都会被判成
> 「鼻翼窄、人中短、眼距开阔」，而鼻部两个深度指标会**全员顶到满值**。
>
> 现已用两个独立参考重新锚定，代码见 `src/modules/mianxiang/thresholds.ts`：
>
> | 指标 | 初稿（猜） | 规范脸实测 | 真人脸实测 | 处理 |
> |---|---|---|---|---|
> | 鼻翼宽 ÷ IOD | 0.58–0.72 | 0.402 | — | 以 0.402 为中心重设 |
> | 人中长 ÷ IOD | 0.28–0.40 | 0.148 | — | 以 0.148 为中心重设 |
> | 眼距 ÷ 眼宽 | 0.9–1.15 | 1.43 | 1.33 | 以 1.43 为中心重设 |
> | 五眼 | 4.7–5.3 | 5.98 | 5.35 | 以 5.98 为中心重设 |
> | 唇厚 ÷ IOD | 0.28–0.42 | 0.159 | — | 以 0.159 为中心重设 |
> | 鼻尖突出量 | 区间 [0.02,0.18] | 0.410 | 0.354 | **两者都饱和**，改为 [0.24,0.52] |
> | 山根突出量 | 区间 [-0.02,0.12] | 0.222 | 0.205 | **两者都饱和**，改为 [0.13,0.29] |
> | 清晰度（Laplacian 方差） | 拒图 <40 / 判糊 <100 | — | **10.3** | 量级错一个数量级，改为判糊 <6 且**永不拒图** |
>
> 两个参考的来源：
> - **规范脸** = MediaPipe 官方 `canonical_face_model`（468 顶点标准化参考脸），投影到图像坐标
> - **真人脸** = MediaPipe 官方测试图上 FaceLandmarker 的真实输出（478 点）
>
> 两者在深度类指标上高度一致（0.410 vs 0.354、0.222 vs 0.205），可以互相印证。
>
> **仍需注意**：这只锚定了「中和」的**中心**，带宽（±8%/±15%）依旧是工程判断，
> n=2 定不出方差。真正的标定需要真实样本回归 —— 代码中标 `CALIBRATE` 的就是这些。

### 0.3 特征状态

| status | 含义 | AI 可否引用 |
|---|---|---|
| `measured` | 直接从关键点算出 | ✅ 可作为论断依据 |
| `inferred` | 从像素/阴影/z 值间接推导 | ⚠️ 必须弱化措辞 |
| `self_reported` | 用户自填 | ⚠️ 需注明来源 |
| `unavailable` | 本次采集无法获得 | ❌ **禁止任何论断** |

### 0.4 置信度

`confidence ∈ [0,1]`，由三部分相乘：
```
confidence = qualityFactor × detectorScore × methodPrior
```
- `qualityFactor`：照片质量门控得分（光照/清晰度/姿态角，见 `05-capture-guide.md`）
- `detectorScore`：MediaPipe 自身给的置信度（如 `handedness.score`、face presence）
- `methodPrior`：方法固有可靠度（几何测量 0.95；明暗推导 0.5；掌纹提取按管线响应强度动态给）

`confidence < 0.35` 的特征降级为 `unavailable`。

### 1.1 三停（上停 / 中停 / 下停）

| 度量 | 定义 |
|---|---|
| `upperCourt` | `y(眉心线) − y(10)`，眉心线 = `(y(107)+y(336))/2` |
| `middleCourt` | `y(2) − y(眉心线)`（2 = 鼻底 subnasale） |
| `lowerCourt` | `y(152) − y(2)` |
| 三者各除以总和 → `r上 : r中 : r下` |

| 条件 | band | 传统术语 | 释义要点 | 出处 |
|---|---|---|---|---|
| 三者两两之差 ≤ 0.04 | `balanced` | **三停平均** | 一生运势平稳，各阶段无大起落 | 麻衣神相 |
| `r上` 最大且 ≥ 0.38 | `high` | **天庭饱满 / 上停有余** | 早年得势，思虑型 | 麻衣神相 |
| `r上` ≤ 0.29 | `low` | **上停狭窄** | 早年需自立，务实取向 | 麻衣神相 |
| `r中` ≥ 0.38 | `high` | **中停丰隆** | 中年主运，意志与执行居优 | 神相全编 |
| `r中` ≤ 0.29 | `low` | **中停扁平** | 中年宜稳守，借助外缘 | 神相全编 |
| `r下` ≥ 0.38 | `high` | **地阁方圆 / 下停有余** | 晚运厚实，重根基与不动产 | 麻衣神相 |
| `r下` ≤ 0.29 | `low` | **下停尖削** | 晚年宜早作规划，宜养生 | 柳庄相法 |

> ⚠️ **发际线警告**：landmark 10 是 Face Mesh 网格顶端，与真实发际线有偏差（额头高/发际后移者尤甚）。`upperCourt` 的 `methodPrior` 只给 **0.65**。可选增强：加载 `ImageSegmenter`（selfie multiclass，含 hair 类）取头发/皮肤边界作为真实发际线，此时 `methodPrior` 提到 0.9。

### 1.2 五眼

```
eyeUnit   = (dist(33,133) + dist(362,263)) / 2     // 单眼宽均值
faceWidth = dist(127, 356)
fiveEye   = faceWidth / eyeUnit                      // 理想 ≈ 5.0
innerGap  = dist(133, 362) / eyeUnit                 // 两眼间距，理想 ≈ 1.0
```

| 条件 | band | 术语 | 释义 |
|---|---|---|---|
| `fiveEye ∈ [4.7, 5.3]` | `balanced` | **五眼匀称** | 五官格局端正，人际关系顺畅 |
| `fiveEye > 5.3` | `high` | **面阔眼小** | 格局开阔，但宜留意专注与细节 |
| `fiveEye < 4.7` | `low` | **眼大面窄** | 感受敏锐，宜留心情绪起伏 |
| `innerGap ∈ [0.9, 1.15]` | `balanced` | **两眼间距适中** | 心胸开阔，不计小节（田宅宫佳） |

### 1.4 十二宫

统一给三类度量：`fullness`（饱满度）、`width`（宽度比）、`blemish`（纹痣瑕疵）。

- `fullness` = 区域内 landmark 平均 z（越负越突出）归一化 + 区域高光面积占比。`status: "inferred"`，`methodPrior = 0.55`。
- `blemish` = 区域灰度做 Laplacian，高频能量占比 → 皱纹/疤痕代理。`methodPrior = 0.5`。

| 宫位 | 部位 | 主要度量 | 佳象术语 | 不足术语 |
|---|---|---|---|---|
| **命宫** | 印堂（两眉之间） | `browGap/eyeUnit`、`fullness`、竖纹能量 | 印堂饱满宽广 | 命宫狭窄 / 悬针纹 |
| **财帛宫** | 鼻头鼻翼 | `tipFullness`、`alarWidth`、`nostrilShow` | 准头丰圆、鼻孔不露 | 准头无肉、鼻孔外露 |
| **兄弟宫** | 眉 | `browLenRatio`、`browDensity`、`browTailDispersion` | 眉清顺长 | 眉毛稀疏 / 杂乱 |
| **田宅宫** | 眉眼之间 | 眉下缘→眼上睑距离 ÷ eyeUnit（佳 ≥ 1.0） | 田宅宽阔 | 田宅狭窄 |
| **男女宫** | 眼下泪堂 | 卧蚕高光带检测、下眼睑暗度 | 卧蚕明显 | 泪堂青黑 / 凹陷 |
| **疾厄宫** | 年寿（鼻梁中） | `bridgeDeviation`、横纹能量 | 年寿隆起光滑 | 年寿低陷 / 有横纹 |
| **迁移宫** | 额角（127/356 上方） | 太阳穴宽 ÷ 颧宽、`fullness` | 迁移饱满 | 迁移低陷 |
| **奴仆宫** | 地阁两侧 | 下颌 `fullness`、腮部宽度 | 地阁方圆 | 腮部尖削 |
| **官禄宫** | 额中 | 额高 ÷ IOD、额宽 ÷ 颧宽、横纹数 | 官禄宽广饱满 | 官禄狭窄 / 乱纹 |
| **福德宫** | 眉上外侧 | `fullness`、横纹能量 | 福德平满 | 福德低陷 |
| **相貌宫** | 整体 | `symmetryScore`、三停均衡度 | 五官端正、三停平均 | 五官不匀 |
| **父母宫** | 日月角（左右额） | 左右额高差 ÷ IOD | 日月角隆起对称 | 一方低陷 |

**对称性得分**：用 `facialTransformationMatrixes` 求出面部中轴，把左侧点镜像到右侧，取 68 组对应点的平均欧氏偏差 ÷ IOD，映射：
`symmetryScore = clamp(1 − dev/0.08, 0, 1)`。≥0.85 → 「五官端正」。

### 1.5 气色（Complexion）

**采样区域**（用 landmark 多边形做 mask）：额中、左右颧、鼻头、下巴。
**流程**：sRGB → 线性化 → 转 CIELab → 剔除高光（L>95）与阴影（L<20）像素 → 取各区中位数。

| 度量 | 定义 |
|---|---|
| `L_mean` | 明度 |
| `a_rel` | 各区 a\*（红度）− 全脸 a\* 中位数 → **相对红润度**（抵消白平衡） |
| `b_rel` | 各区 b\*（黄度）相对值 |
| `uniformity` | 1 − 各区 L 的标准差 / 全脸 L |
| `gloss` | 高光像素占比 |

| 条件 | 术语 | 释义 |
|---|---|---|
| `a_rel > 0` 且 `gloss` 适中 且 `uniformity ≥ 0.85` | **红润有光泽** | 气血调和，状态在线 |
| `b_rel > 0` 且 `L_mean` 高 | **黄明透亮** | 传统主运势渐开 |
| `L_mean` 高 且 `a_rel ≈ 0` | **白净明亮** | 清贵之气 |
| `a_rel < 0` 且 `L_mean` 高 | **苍白少华** | 宜注重休息与营养 |
| `uniformity < 0.7` 或 `L_mean` 低 | **气色欠匀 / 暗淡** | 近期宜调整作息 |

> ⚠️ **气色是全项目可靠度最低的一项**。受白平衡、色温、化妆、屏幕补光严重干扰。
> 强制措施：① `methodPrior = 0.45` 封顶；② 检测到强色偏（全图 a\*/b\* 极端）时直接标 `unavailable`；③ System Prompt 中气色只允许**关联到作息与状态**，**严禁**任何疾病指向（原文「病痛将至」「肝胆问题」全部删除）。

### 1.6 五形格局（金木水火土）

综合分类器，输入 4 个量：
```
FW  = faceWidth / faceHeight            // 面宽高比
JC  = jawWidth(172,397) / faceWidth     // 颌颧比
FC  = foreheadWidth(127,356) / faceWidth// 额颧比
CR  = 下颌轮廓曲率（152 附近曲率半径 ÷ IOD）
```

| 形 | 判据 | 性格要点（改写后） | 出处 |
|---|---|---|---|
| **金形** | `FW ≥ 0.78`、`JC ≥ 0.82`、`CR` 小（方颌） | 刚毅果断，明辨是非，重义气 | 麻衣神相 |
| **木形** | `FW ≤ 0.68`、`JC ≤ 0.75` | 仁厚耿直，有才华，坚持原则 | 麻衣神相 |
| **水形** | `FW ≥ 0.75`、`CR` 大（圆润）、`JC ∈ [0.75,0.85]` | 智慧灵活，适应力强，善交际 | 神相全编 |
| **火形** | `FC ≥ 0.88` 且 `JC ≤ 0.72`（上宽下尖） | 热情积极，行动力强，宜控节奏 | 麻衣神相 |
| **土形** | `FW ≥ 0.80`、`JC ≥ 0.85`、`CR` 中等（方圆） | 稳重踏实，讲信用，重承诺 | 神相全编 |
| **兼形** | 无单一形得分 ≥ 0.55 | 兼具多形之长，可塑性强 | — |

实现为**软分类**：各形算一个 0–1 得分，输出 top-1 + top-2 及得分，让 AI 描述「以某形为主，兼某形」。

### 1.7 脸型标签（供 UI 展示）

沿用 Face-Reading 词表，由 `FW / JC / FC / CR` 直接判定：
`圆脸`（FW高+CR大）、`瓜子脸`（FC>JC，下颌收窄，CR小）、`国字脸`（FW高+JC高+方颌）、`由字脸`（FC<JC，下宽上窄）、`甲字脸`（FC>JC，额宽下尖，比瓜子脸更显额宽）。

### 1.8 纹痣（痣 · 卧蚕 · 法令纹）

实现：`src/modules/mianxiang/marks.ts`。三项都是**像素推断**，一律以 `inferred` 出具。
传统相法在这一块的断语最密（痣按宫位断、卧蚕主男女宫、法令主威权），
但也最容易误检，因此每一项都有明确的作废路径。

| 项 | 度量 | 判据 | 失败时 |
|---|---|---|---|
| 痣 | 小窗（IOD×0.008）与大窗（IOD×0.05）的局部亮度差；连通域后按面积、长宽比、紧实度过滤 | 比周围肤色暗 >13%，且面积落在 `[πr²×0.4, π(IOD×0.035)²]`、长宽比 <2.5、紧实度 >0.45 | 检出 >12 颗即判为雀斑/痘印/噪点，整项作废标 `low_confidence` |
| 卧蚕 | 下睑缘下方 IOD×0.13 的条带内逐行取中位亮度，求「亮脊 − 其下暗沟」的落差；另与颊部基准比较得深陷度 | `ridge ≥ 0.17` 为卧蚕丰隆；否则 `hollow ≥ 0.14` 为泪堂深陷 | 采样不足标 `low_confidence` |
| 法令纹 | 沿鼻翼→口角方向（延长 40%）逐点在垂线上找局部最暗处，取深度中位数与「测得到纹沟的采样点占比」 | `depth ≥ 0.13` **且** `continuity ≥ 0.5` 为深长；口角以下仍连续则判「法令过口」 | 采样不足标 `low_confidence` |

**为什么 depth 和 continuity 要同时过线**：只深不连的多半是鼻侧阴影，
单看深度会把侧光拍的脸全判成法令深长。

排除区（否则每张脸都能「测出」几十颗痣）：双眼、双眉、唇、两个鼻孔各自的小区，
以及面部轮廓向内收 8% 之外的边缘（那里混着头发、耳朵与背景）。

## 二、手相（Shouxiang）

**输入**：MediaPipe `HandLandmarker`，1–2 张手掌照（推荐左右手各一张），每手 21 landmarks + `handedness`
**质量门控**：手掌正对镜头（掌平面法向与视轴夹角 ≤ 20°）、五指自然张开、手占画面 ≥ 40%、无强阴影

### 2.1 关键点与掌坐标系

21 点：`0` 腕、`1–4` 拇指、`5–8` 食指、`9–12` 中指、`13–16` 无名指、`17–20` 小指；MCP = `5,9,13,17`。

**透视归一化（关键步骤）**：
用 4 个稳定锚点 `0(腕)`、`5(食指MCP)`、`17(小指MCP)` 以及由它们构造的第 4 点，求单应矩阵 `H`，把手掌映射到**标准掌画布 512×512**：

```
标准画布约定：
  x ∈ [0,512] 从拇指侧 → 小指侧（左手先做水平翻转，统一为右手朝向）
  y ∈ [0,512] 从指根 → 腕部
  掌宽 PW = dist(5,17) 映射为 256px，居中
```

归一化后，掌纹的位置先验才有稳定意义。**所有掌纹判据都在这个坐标系里定义。**

### 2.2 手型 / 指形（从 21 点直接算，可靠度高）

| 度量 | 公式 |
|---|---|
| `palmLen` | `dist(0, 9)` |
| `palmWidth` | `dist(5, 17)` |
| `palmAspect` | `palmWidth / palmLen`（越大越方阔） |
| `fingerLen_i` | 各指分段长之和（MCP→PIP→DIP→TIP），比单纯 MCP→TIP 抗弯曲 |
| `fingerPalmRatio` | `fingerLen_中指 / palmLen` |
| `thumbRatio` | `fingerLen_拇指 / palmLen` |
| `indexRingRatio` | `fingerLen_食指 / fingerLen_无名指` |
| `pinkyReach` | 小指指尖 y 相对无名指 DIP（`15`）的位置 → 小指长短传统判据 |
| `tipTaper` | 指尖轮廓宽度 ÷ DIP 处宽度（需手部轮廓，来自肤色分割掩膜） |

**手型五分类**（软分类，输出得分）：

| 手型 | 判据 | 性格 / 职业倾向 | 出处 |
|---|---|---|---|
| **原始手（实心手）** | `palmAspect ≥ 0.82`、`fingerPalmRatio ≤ 0.85`、掌厚（轮廓面积/掌长²高） | 行动力强，朴实稳重，执行力佳 | 神相全编 |
| **方形手（智慧手）** | `palmAspect ∈ [0.75,0.85]`、`tipTaper ≥ 0.85`（指尖方） | 逻辑强，有计划，守规矩 → 管理/财务/法律/工程 | 水镜神相 |
| **圆形手（情感手）** | `palmAspect ≥ 0.78`、`tipTaper ∈ [0.65,0.8]`、轮廓曲率大 | 情感丰富，善交际，直觉敏锐 → 艺术/服务/教育 | 水镜神相 |
| **锥形手（理想手）** | `palmAspect ≤ 0.72`、`fingerPalmRatio ≥ 0.95`、`tipTaper ≤ 0.65` | 创造力强，追求完美 → 设计/创作/策划 | 神相全编 |
| **精神手（哲学手）** | `palmAspect ≤ 0.70`、`fingerPalmRatio ≥ 1.0`、指节突出度高 | 善思考，重精神层面 → 研究/教学 | 神相全编 |

**五指长短**：

| 条件 | 术语 | 释义 |
|---|---|---|
| `thumbRatio ≥ 0.62` | **拇指长而有力** | 意志力强，领导力佳 |
| `thumbRatio ≤ 0.52` | **拇指短小** | 随和易协作，宜加强主见 |
| `indexRingRatio ≥ 1.02` | **食指长（高于无名指）** | 野心与领导欲强 |
| `indexRingRatio ≤ 0.94` | **无名指长** | 审美与艺术天分佳 |
| 小指尖 ≥ 无名指 DIP | **小指长** | 沟通表达力佳 |
| 小指尖 < 无名指 DIP | **小指短** | 内敛，宜主动表达 |
| 中指 `fingerLen_中/palmLen ≥ 1.0` | **中指长** | 严谨认真，责任感强 |

> 说明：`indexRingRatio` 即学界常说的 2D:4D 指长比。本项目**仅作为传统手相「木星丘/太阳丘倾向」的量化代理**使用，不引用任何生物学/激素相关论断。

### 2.3 掌纹提取管线（本项目最关键的自研模块）

**问题**：MediaPipe 21 点是纯关节点，**不含任何掌纹信息**。必须自建 CV 管线。

**管线（全部在 Web Worker + OffscreenCanvas 中运行）**：

```
① ROI + 透视归一化
   21 点 → 掌四边形 → 单应矩阵 H → 512×512 标准掌画布
② 通道选择
   取绿通道（皮肤纹理对比最优，优于灰度加权）
③ 局部对比增强
   CLAHE，tile 8×8，clipLimit 2.0
④ 谷线增强（掌纹是暗谷，不是亮脊）
   Gabor 滤波器组：8 个方向 (0°,22.5°,…,157.5°)
   λ = 6px, σ = 3, γ = 0.5  （对应 512 画布上 3–6px 的纹宽）
   取各方向最大响应 → responseMap
   ⚙️ 用可分离核 + Web Worker，实测目标 < 150ms
⑤ 二值化
   对 responseMap 做自适应阈值（局部均值 − k·局部标准差，k=0.35）
⑥ 形态学清理
   闭运算（3×3）桥接断口 → 移除面积 < 40px 的连通域
⑦ 细化
   Zhang-Suen 骨架化 → 1px 骨架
⑧ 折线追踪
   骨架图 → 端点/分叉点检测 → 追踪成 polyline
   → 合并夹角 < 25° 且端点距 < 12px 的相邻段
⑨ 主线归类（位置先验打分）
   见下表
⑩ 逐线度量
   长度、深度、连续性、曲率、分叉、岛纹
```

**⑨ 主线归类先验**（标准掌画布坐标，`(0,0)` 左上 = 拇指侧指根）：

| 线 | 起点区 | 终点区 | 主方向 | 曲率符号 | 附加约束 |
|---|---|---|---|---|---|
| **生命线** | 拇指侧上部 `x<0.35W, y<0.35H` | 腕部 `y>0.75H` | 弧形绕拇指根 | 凸向小指侧 | 与金星丘边界近似同心 |
| **智慧线** | 与生命线起点接近或略下 `x<0.4W, y∈[0.25,0.45]H` | 掌中至小指侧 `x>0.6W` | 近水平偏下 | 直或缓下弯 | 位于感情线**下方** |
| **感情线** | 小指侧 `x>0.75W, y∈[0.2,0.4]H` | 食指/中指根方向 `x<0.45W` | 近水平 | 上凸 | 位于智慧线**上方**，四线中最靠指根 |
| **命运线** | 腕部 `y>0.7H` | 中指根 `x∈[0.4,0.6]W, y<0.3H` | 近垂直 | 直 | 与掌轴夹角 < 25° |
| **太阳线** | 掌中下部 | 无名指根 `x∈[0.6,0.75]W, y<0.3H` | 近垂直 | 直 | 常短、常缺失 |
| **婚姻线** | 小指侧掌缘 `x>0.9W, y∈[0.15,0.3]H` | 向掌心短横 | 水平 | — | 短线，可多条 |

打分：`score = w1·起点匹配 + w2·终点匹配 + w3·方向匹配 + w4·曲率匹配 + w5·长度合理性`。
每条主线取最高分候选，`score < 0.45` → 该线 `status: "unavailable"`。

**⑩ 逐线度量与规则表**：

| 度量 | 定义 |
|---|---|
| `lengthRatio` | 折线长 ÷ 掌宽 PW |
| `depth` | 沿线采样的 Gabor 响应均值（归一化 0–1）→ 深浅 |
| `continuity` | 1 − (断口数 × 断口平均长度 / 总长) |
| `curvature` | 矢高 ÷ 弦长 |
| `branches` | 分叉点数 |
| `islands` | 闭合环数 |
| `doubled` | 是否存在近平行的第二条同类线 |

| 线 | 条件 | 术语 | 释义要点（改写后） |
|---|---|---|---|
| 生命线 | `lengthRatio ≥ 1.0` 且 `depth ≥ 0.6` | **深长清晰** | 体质根基好，活力充沛 |
| 生命线 | `lengthRatio ≤ 0.65` 或 `depth ≤ 0.35` | **短浅** | 宜规律作息、注重养护（⚠️ 不作寿命论断） |
| 生命线 | `continuity ≤ 0.7` | **断续** | 精力有起伏，宜留意节奏 |
| 生命线 | `islands ≥ 1` | **有岛纹** | 传统提示某阶段宜多加保养 |
| 生命线 | `doubled` | **双生命线** | 恢复力强，韧性佳 |
| 智慧线 | `lengthRatio ≥ 0.85` 且 `curvature ≤ 0.08` | **长而直** | 逻辑思维强，理性分析佳 |
| 智慧线 | `lengthRatio ≥ 0.85` 且 `curvature ≥ 0.15` | **长而弯** | 直觉强，富创造力 |
| 智慧线 | `lengthRatio ≤ 0.6` | **短** | 务实主义，重执行 |
| 智慧线 | `branches ≥ 1`（末端） | **叉状末端** | 多才多艺，一专多能 |
| 感情线 | `curvature ≥ 0.12` 且末端上扬 | **上扬** | 热情开朗，主动表达 |
| 感情线 | 末端下垂 | **下垂** | 敏感重情，宜多沟通 |
| 感情线 | `lengthRatio ≥ 0.9` 且 `curvature ≤ 0.08` | **长而平直** | 情感稳定，专一 |
| 感情线 | `branches ≥ 2` | **多支分叉** | 情感丰富，人际面广 |
| 命运线 | `depth ≥ 0.55` 且 `continuity ≥ 0.85` | **深长直** | 事业方向清晰，发展顺遂 |
| 命运线 | `continuity ≤ 0.7` | **断续** | 事业多阶段转折，宜灵活调整 |
| 命运线 | `status: unavailable` | **无明显命运线** | 传统主自由不拘固定轨道 |
| 太阳线 | `depth ≥ 0.5` | **清晰深长** | 才华易被认可 |
| 婚姻线 | 数量 = 1 且 `depth` 高 | **一条深长** | 感情观稳定专一 |
| 婚姻线 | 向上倾斜 | **上扬** | 传统主感情质量佳 |

**降级与人工校正（必须实现）**：
若任一主线 `score < 0.45`，UI 弹出「掌纹识别辅助」界面：把归一化掌图 + 检测到的候选折线叠加显示，用户可**点选把某条候选指定为某主线**，或**手指描摹**补画。校正后的线走同样的度量流程，`status` 标为 `self_reported`，`confidence = 0.7`。

> 这是本模块的产品安全网：宁可让用户参与，也不要凭空生成掌纹判断。

### 2.4 掌丘（Mounts）

在标准掌画布上定义 7 个圆形区域（半径 = 0.12W）：

| 丘 | 中心（标准掌坐标） |
|---|---|
| 木星丘 | 食指 MCP 正下方 0.10H |
| 土星丘 | 中指 MCP 正下方 0.10H |
| 太阳丘 | 无名指 MCP 正下方 0.10H |
| 水星丘 | 小指 MCP 正下方 0.10H |
| 金星丘 | 拇指根，`x≈0.18W, y≈0.62H` |
| 月丘 | 小指侧下方，`x≈0.82W, y≈0.68H` |
| 火星丘 | 掌心，`x≈0.5W, y≈0.5H` |

**饱满度度量**（`status: "inferred"`，`methodPrior = 0.5`）：
```
fullness = 0.6 × (区域中位亮度 − 掌面中位亮度) / 掌面亮度标准差
         + 0.4 × (区域内 MCP 关键点相对掌平面的 z 突出量, 仅对四指丘可用)
```
再归一化到 0–1。

| band | 术语 | 释义 |
|---|---|---|
| `high` | **丰满** | 该丘所主特质突出 |
| `balanced` | **适中** | 均衡发展 |
| `low` | **平坦** | 该方面宜有意培养 |
| `very_high` | **过盛** | 传统提醒宜节制（如木星丘过盛 → 宜留意自我评价） |

各丘释义沿用 kanxiang（木星=自信野心领导、土星=稳重责任、太阳=艺术乐观、水星=沟通商业、月丘=想象直觉、金星=生命力热情、火星=勇气行动力）。

### 2.5 掌色

同面相气色流程，采样掌心 + 掌缘，取 Lab。
`红润 / 苍白 / 偏黄 / 偏青` 四档，**仅关联作息与状态，禁止疾病指向**（原文「肝胆问题」「循环系统问题」删除）。`methodPrior = 0.45`。

### 2.6 左右手

`HandLandmarker` 的 `handedness` 直接给出左右（含置信度）。

| 情况 | 输出 |
|---|---|
| 双手都采集 | 分别输出 `left` / `right` 特征集 + 一个 `comparison` 对象 |
| 仅一只手 | 只输出该手，`comparison.status = "unavailable"` |

`comparison` 度量：主要线的 `lengthRatio / depth / continuity` 逐项差值。

| 条件 | 术语 | 释义（沿用 kanxiang） |
|---|---|---|
| 右手主线综合评分 > 左手 + 0.1 | **右优于左** | 后天努力改善先天格局 |
| 左手 > 右手 + 0.1 | **左优于右** | 天赋尚有发挥空间 |
| 差值 ≤ 0.1 | **左右相似** | 先天与后天一致 |

> 左手主先天、右手主后天（《神相全编》）。UI 引导优先采集**惯用手**，双手为加分项。

### 2.7 明确不做的项

| 项 | 原因 |
|---|---|
| 干手 / 湿手 | 照片无法判断 |
| 软手 / 硬手 | 需触觉 |
| 指甲半月纹 / 纵横纹 | 手机摄像头分辨率与对焦不足，且易导向医疗暗示 |

→ 全部 `status: "unavailable"`，或转为可选自评（软硬手可让用户自选，`self_reported`）。

## 三、骨相（Guxiang）

**输入**：**两张照片** —— ① 正面人脸照（复用 `FaceLandmarker`）② 侧面人脸照（同模型）；③ 可选：半身/全身照（`PoseLandmarker`）
**定位**：骨相**没有专用模型**，是一个**派生模块**——从面部轮廓与体态关键点反推骨架特征。这一点必须对用户明示。

### 3.1 为什么要侧面照

正面照只能给出「宽度」，无法给出「前后径」。而头型分类（圆/长/方/扁）本质是**前后径 vs 左右径**之比。加一张侧面照即可估算：

```
headWidth  ← 正面照 dist(234, 454) / IOD_front
headDepth  ← 侧面照 (最前点 ≈ 鼻根附近轮廓, 最后点 ≈ 后脑轮廓) / IOD_side
cephalicIndex ≈ headWidth / headDepth        // 头指数（左右径 ÷ 前后径）
```

> ⚠️ 诚实说明：Face Mesh 网格**不覆盖颅顶与后脑**，`headDepth` 只能取到侧面照的**面部轮廓 + 网格边缘**，且常被头发影响。`methodPrior = 0.5`，并在报告中明确标注「基于面部框架推估」。
> 若用户不提供侧面照：`headShape` 直接标 `unavailable`，**不允许 AI 猜测头型**。

### 3.2 九骨可测性总表（必读）

| 九骨 | 可测性 | 数据来源 | status |
|---|---|---|---|
| ① **颧骨** | ✅ 好 | 正面：颧宽、突出度、左右差 | `measured` / `inferred` |
| ② **额骨** | ✅ 好 | 正面：额宽、额高、日月角高差 | `measured` |
| ③ **枕骨**（后脑） | ❌ **不可见** | — | `unavailable` |
| ④ **顶骨**（头顶） | ❌ **不可见** | — | `unavailable` |
| ⑤ **颞骨**（太阳穴） | ⚠️ 弱 | 正面：太阳穴宽/凹陷（明暗推导） | `inferred` |
| ⑥ **鼻骨** | ✅ 好 | 正面 + 侧面：鼻梁高度、直曲 | `measured` |
| ⑦ **下颌骨** | ✅ 好 | 正面：下颌角宽、颌角角度、颏形 | `measured` |
| ⑧ **眉骨** | ⚠️ 弱 | 侧面：眉弓突出；正面：眉下阴影梯度 | `inferred` |
| ⑨ **耳后骨** | ❌ **不可见** | — | `unavailable` |

**特殊骨相**（龙骨、虎骨、反骨、脑后见腮、三台骨）：
- 龙骨（颅顶纵脊）、三台骨（额+顶+枕隆起）、反骨（枕骨外翻）、耳后骨 → **全部 `unavailable`**
- 虎骨（头宽 + 颧高）→ 可从正面照近似判定，`inferred`
- 脑后见腮（腮向后扩张）→ 正面照可测「腮宽 vs 颧宽」，`inferred`

> **这是骨相模块的诚实边界。** System Prompt 会硬性禁止 AI 对 `unavailable` 项发言；报告中改为一句提示：「传统骨相中的枕骨、顶骨、耳后骨需实际触诊或多角度观察，本次照片无法获取，故不作论断。」

#### 颧骨（权力骨）

| `zygoAsymmetry` | 左右颧点 y 之差 / IOD（正 = 左高） |

| 条件 | 术语 | 释义（改写后） |
|---|---|---|
| `zygoProminence` 高 | **颧骨高耸** | 主见强，领导与推动力佳 |
| `zygoProminence` 低 | **颧骨平和** | 配合度高，善于协作 |

### 3.4 骨肉关系（本模块最有价值的可测项）

传统「骨多肉少 / 骨少肉多 / 骨肉相称」实际上**可以量化**：

```
boneScore  = 归一化(zygoWidth) + 归一化(bigonialWidth) + 归一化(1/gonialAngle)
fleshScore = 下颌轮廓平滑度 + 颏下（submental）区域厚度 + 面颊填充度(轮廓外扩量)
boneFleshRatio = boneScore / (boneScore + fleshScore)
```

| 条件 | 术语 | 释义（改写后） |
|---|---|---|
| `boneFleshRatio ≥ 0.60` | **骨多肉少** | 刚毅坚强，原则性高；宜多包容柔和 |
| `boneFleshRatio ≤ 0.40` | **骨少肉多** | 温和友善，人缘佳；宜增强决断 |
| `∈ [0.40, 0.60]` | **骨肉相称** | 刚柔并济，平衡发展（传统视为最佳） |

> ⚠️ 原文「骨多肉少 → 晚年需防孤苦」已删（消极断言）。

### 3.5 骨骼粗细

| 数据源 | 度量 |
|---|---|
| Pose（有体照时） | 腕宽/身高比、肘膝关节区宽度、肩宽/身高比 |
| Face（无体照时） | `gonialAngle`（颌角越方 → 骨越粗）+ 眉弓突出 + `boneFleshRatio` |

→ `粗骨型 / 中骨型 / 细骨型`，释义沿用 kanxiang（粗骨=体力充沛直率；细骨=敏感细腻善思；中骨=文武兼备）。

## 四、体相（Tixiang）

**输入**：MediaPipe `PoseLandmarker`（33 landmarks + **worldLandmarks 米制**），1 张全身或半身照
**可选增强**：`ImageSegmenter`（selfie multiclass）取人体轮廓 → 量胸/腰/臀宽
**可选自评**：身高、体重、声音特点、语速、衣着风格（3–5 题，全部可跳过）
**质量门控**：全身可见（头顶到脚踝，或至少到髋）、正面站立、双臂自然下垂或微张、单人

### 4.1 关键点

33 点：`0` 鼻、`2/5` 眼、`7/8` 耳、`11/12` 肩、`13/14` 肘、`15/16` 腕、`23/24` 髋、`25/26` 膝、`27/28` 踝、`31/32` 脚尖。

> **一律使用 `worldLandmarks`**（米制、原点在髋中心），比例与相机距离无关。图像坐标只用于画可视化叠加层。

### 4.2 身体比例

| 度量 | 公式（world 坐标） |
|---|---|
| `shoulderWidth` | `dist(11,12)` |
| `hipWidth` | `dist(23,24)` |
| `shoulderHipRatio` | `shoulderWidth / hipWidth` |
| `torsoLen` | `dist(肩中点, 髋中点)` |
| `legLen` | `dist(髋中点, 踝中点)` |
| `upperLowerRatio` | `torsoLen / legLen` |
| `armLen` | 肩→肘→腕分段和 |
| `neckLen` | `dist(耳中点, 肩中点)` 的垂直分量 |
| `armReach` | 腕 y 相对大腿中点 y（传统「手臂垂至大腿中部」判据） |
| `estHeightProxy` | 头顶估计点 → 踝，仅作**内部比例基准**，**不对外报告绝对身高** |

| 条件 | 术语 | 释义 |
|---|---|---|
| `shoulderHipRatio ≥ 1.45` | **宽肩** | 格局开阔，能担当（不分性别，统一措辞） |
| `shoulderHipRatio ≤ 1.20` | **窄肩 / 骨盆宽** | 亲和包容，重和谐 |
| `upperLowerRatio ≥ 0.95` | **上半身长** | 思考型，善谋划 |
| `upperLowerRatio ≤ 0.80` | **下半身长** | 行动型，执行力佳 |
| `armReach` ≈ 大腿中部 ±5% | **手臂垂至大腿中部** | 比例协调，平衡发展 |
| `neckLen` 相对大 | **长颈** | 气质优雅 |
| `neckLen` 相对小 | **短颈** | 稳重务实，执行力强 |

> ⚠️ **绝对身高不可测**。kanxiang 原文有「男性≥175cm → 气场强大 / <165cm → 格局有限」——这既不可测又带身材歧视，**整节删除**。若用户自评填了身高，只作为体型指数的输入，**不生成任何「高个子格局大/矮个子格局有限」类论断**。

### 4.3 体型分类（谢尔登体质三型）

**MVP 方案（仅 Pose）**：
```
endomorphy_proxy  = hipWidth / shoulderWidth  +  躯干宽厚代理
mesomorphy_proxy  = shoulderWidth / torsoLen  +  肢体粗细代理
ectomorphy_proxy  = (torsoLen + legLen) / shoulderWidth      // 线性度
```

**增强方案（+ ImageSegmenter）**：沿躯干轴在胸、腰、髋三个高度切线，量轮廓宽度 → `chestW / waistW / hipW`，得到远更可靠的体型判据。
**自评增强**：若用户填了身高体重 → BMI，作为 endomorphy 的直接输入。

| 型 | 判据 | 性格要点（改写后） | 健康提示（生活方式，非诊断） |
|---|---|---|---|
| **内胚型（丰腴型）** | 髋/肩比高、腰宽比高、BMI 偏高 | 温和友善，情绪稳定，包容力强 | 建议保持规律有氧与均衡饮食 |
| **中胚型（健壮型）** | 肩宽/躯干比高、肢体粗壮 | 行动力强，自信，勇于挑战 | 建议注意运动前热身与恢复 |
| **外胚型（清瘦型）** | 线性度高、肩窄、肢体细长 | 思维敏捷，敏感细腻，重内涵 | 建议注重营养摄入与力量训练 |
| **平衡型** | 各项居中 | 刚柔并济，适应力强，全面发展 | 保持现有作息 |
| **混合型** | 无单一型得分 ≥ 0.5 | 多面性，可塑性强 | — |

> ⚠️ kanxiang 原文的「注意心血管疾病、糖尿病 / 高血压」等**疾病名一律删除**，改为纯生活方式建议 + 「如有健康疑虑请咨询专业医生」。

### 4.4 体态（站姿）

| 度量 | 公式 |
|---|---|
| `trunkTilt` | 向量（髋中点→肩中点）与铅垂线夹角（度） |
| `headForward` | 耳中点 x − 肩中点 x，÷ 肩宽（正面）；侧面照更准 |
| `shoulderSlope` | 左右肩连线与水平线夹角 |
| `shoulderRoll` | 肩 z 相对耳 z（圆肩代理，需 z 值） |
| `weightShift` | 髋中点 x − 踝中点 x，÷ 肩宽 |
| `stanceWidth` | `dist(27,28) / shoulderWidth` |
| `kneeAlign` | 膝中点相对髋踝连线的偏移 |

| 条件 | 术语 | 释义 |
|---|---|---|
| `trunkTilt ≤ 3°` 且 `shoulderSlope ≤ 2°` | **直立挺拔 / 平肩** | 自信稳重，气场沉着 |
| `trunkTilt ∈ (3°,8°]` 前倾 | **微微前倾** | 积极进取，富有热情 |
| `trunkTilt` 后仰 | **微微后仰** | 放松自信，不拘小节 |
| `shoulderSlope ≥ 4°` | **斜肩** | 传统主随和；现代提示：宜留意用侧习惯 |
| `shoulderRoll` 高 | **圆肩** | 长期伏案倾向，建议加强背部舒展 |
| `weightShift ≥ 0.12` | **重心偏移** | 建议留意站姿习惯 |
| `stanceWidth ≥ 0.9` | **双脚分开** | 稳重踏实，安全感强 |
| `stanceWidth ≤ 0.4` | **双脚并拢** | 自律优雅，或较为拘谨 |

> ⚠️ 原文「歪斜站立 → 性格不均衡」「严重驼背 → 性格软弱」改写为体态健康提示，去掉人格贬损。
> **坐姿 / 走姿 / 睡姿**：单张静态照片无法获取 → `unavailable`（除非未来做视频模式）。

### 4.5 肌肤与气色

采样面部 + 颈部 + 手臂裸露区，Lab 分析，同 1.5。`红润 / 苍白 / 偏黄 / 暗沉`，**仅关联作息状态**。
毛发（发量/发质）：需分割模型，MVP 标 `unavailable`。

### 4.6 可选自评项（补足照片测不到的维度）

在体相报告生成前，弹一个可跳过的 3 题小问卷（结果标 `self_reported`）：

| 题 | 选项 | 对应 kanxiang 章节 |
|---|---|---|
| 你的声音更接近？ | 洪亮 / 柔和 / 低沉 / 清亮 | 七、声音与言语 |
| 你说话的节奏？ | 偏快 / 适中 / 偏慢 | 同上 |
| 你日常穿着更偏向？ | 整洁得体 / 随意自然 / 时尚前卫 / 传统保守 / 朴素简约 | 九、衣着与打扮 |

> 「衣着色彩偏好」「睡姿」不问——前者与相术关联牵强，后者过于私密。

### 4.7 明确不做的项

绝对身高体重（除非自评）、乳房（整节删除）、睡姿、声音自动分析（未来可做录音模式）、衣着色彩自动识别。

## 五、本地评分卡（不经过 AI）

报告页的星级评分**由本地规则算出**，不让 AI 生成——保证同一张照片每次评分一致。

```
dimensionScore(d) = Σ featureWeight(f) × bandValue(f) × confidence(f)
                    ─────────────────────────────────────────────────
                            Σ featureWeight(f) × confidence(f)
```
`bandValue`：`very_low=0.1, low=0.3, balanced=0.75, high=0.9, very_high=0.6`
（注意：`very_high` 低于 `high`——传统相术以「中和为贵、过犹不及」，过盛反而减分。）

映射到 5 个展示维度（1–5 星）：

| 维度 | 主要贡献特征 |
|---|---|
| **气度格局** | 三停均衡、五形得分、对称性、肩宽比、骨肉相称 |
| **才智思辨** | 额骨、印堂、眼神清明、智慧线、头型 |
| **人际情感** | 眉、口角、感情线、田宅宫、体态开放度 |
| **执行意志** | 下颌骨、拇指、命运线、中胚倾向、站姿 |
| **根基福泽** | 下停/地阁、耳、鼻翼准头、金星丘、生命线 |

⚠️ 展示时必须标注「本评分为传统相术特征的量化换算，仅供娱乐参考」。
