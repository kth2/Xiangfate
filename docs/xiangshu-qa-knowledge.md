## 0. 全局原则（所有类型共用）

### 术士常见应对习惯

1. 先观形神，再落细节，不急着答具体问题。
2. 综合论断（面 + 手 + 骨 + 体），不单凭一处。
3. 给倾向与方向，而非绝对定数。
4. 给「宜做什么」比只说「会怎样」更有用。
5. 婚姻、寿命、子女尤其谨慎，留有余地。
6. 强调可调：「相由心生」「积善改相」「气色可养」。

第 3、4、6 条与本项目的语气规范天然一致，可直接照用；
第 5 条在本项目里**加强**为：这三类不留余地地不作论断（见第 7 节）。

### 共通高频问题（任何类型都可能问）

| 主题 | 求测者常问 | 术士常见应对方向 | 本项目口径 |
|------|------------|------------------|-----------|
| 整体运势 | 这一生怎么样？有没有大富大贵？ | 先总断形神与格局，再分早中晚 | 照用，但「大富大贵」转为格局与节奏描述，不给财富量级 |
| 财运 | 能不能赚到钱？正财还是偏财？何时发？ | 看财帛相关部位；有根则稳、无根则漂 | 只谈理财风格与用力方式，不答「何时」「多少」 |
| 事业 | 适合做什么？该不该换工作？有没有官运？ | 看官禄/骨气/神；给方向（文/武、稳/进） | 照用；「该不该换」转为「这类特征在什么环境里更顺」 |
| 婚姻 | 何时结婚？对象什么样？会不会离/克？ | 看夫妻宫/感情线等；刑克可化解，重互补 | **只谈相处方式与表达倾向**；不谈成败、刑克、时间 |
| 健康寿命 | 身体如何？能活多久？有大灾吗？ | 看神气、气色、生命线等；劝养 | **只给作息、姿态、精力建议**；不作寿夭判断、不指向疾病 |
| 子女 | 有没有孩子？几个？男女？ | 看子女相关纹/宫 | **不作论断**，说明本项目不涉及该主题 |
| 流年 | 今年怎样？最近有劫吗？何时转运？ | 看流年部位气色 + 对应变化 | 气色只关联**当下状态与作息**，不挂任何年份月份 |
| 性格 | 我是什么性格？别人怎么看我？ | 从五官、神、骨肉综合 | 照用。这块最稳，可作为主力内容 |

## 1. 面相（Mianxiang）

### 求测者最常问

三庭匀不匀？天庭饱不饱？印堂宽不宽、有没有官运？鼻子好不好（财帛宫）？眼睛有没有神、会不会被人骗？
嘴巴厚不厚、会不会漏财/口舌？下巴方不方、晚年好不好？有没有富贵相、官相？气色怎么样、最近是不是走霉运？
法令纹深代表什么？痣长在哪里好/不好？十二宫里哪一宫最好/最弱？

### 术士常见应对方式

1. 先看整体形神（清浊、精神），再落具体部位。
2. 用十二宫框架：命、财帛、官禄、迁移、疾厄、夫妻、子女等。
3. 断语风格：「主……」「多主……」「宜……」「防……」。
4. 气色重于静态骨相：同脸气色好则暂吉，晦则暂凶。
5. 强调相随心转，劝改习惯、修心。

### 关键部位速查

| 部位 | 传统关注 | 常见温和断法 |
|------|----------|--------------|
| 天庭/额 | 早年、思路、官禄 | 饱满主思路开阔；窄宜专注一事 |
| 印堂 | 事业、贵人、心绪 | 宽明主较顺；窄滞宜稳中求 |
| 眉 | 性格、兄弟、魄力 | 清秀主敏；浓杂宜收敛躁气 |
| 眼 | 神、心性、察人 | 有神主心有主；无神宜养神 |
| 鼻 | 财帛、疾厄、意志 | 梁正头圆多主财有根；尖薄宜合作借势 |
| 口唇 | 表达、出纳、食禄 | 方厚主守；尖薄防漏、宜谨言 |
| 地阁/下巴 | 晚年、根基 | 丰主后运较稳；削宜厚积 |
| 气色 | 当下运势 | 明润气充；晦滞宜养气 |

### 本项目的边界

- **痣、法令纹不在特征库内**（关键点测不到痣，法令纹未做纹路提取）。被问到时如实说「本次测量没有覆盖」，
  不得凭「一般来说」补足。
- 疾厄宫只能连到作息与精力，不得出现任何器官或病名。
- 上停来自面部网格顶端而非真实发际线，置信度天然偏低，措辞需相应缓和。

### 预设问题

我的面相整体格局如何 / 财运方面有什么提示 / 事业适合什么方向 / 感情相处上要注意什么 /
近期气色透露出什么状态 / 晚年运势怎么看 / 性格上别人可能怎么看我

## 2. 手相（Shouxiang）

### 求测者最常问

生命线长短有没有关系、会不会短命？智慧线分叉代表什么？感情线往上还是往下、婚姻好不好？
有没有事业线/命运线、会不会大起大落？金星丘高不高？手指长短、手型代表什么性格？
看左手还是右手？岛纹、十字、星纹是好是坏？什么时候结婚/换工作/破财？

### 术士常见应对方式

1. 先定主手（传统男左女右；现代多以惯用手为主，另一手为先天/潜力）。
2. 三大主线优先：生命线、智慧线、感情线。
3. **必须澄清：生命线短 ≠ 短命**，它主体质、精力、生活节奏。
4. 纹路会变，多说「目前状态」而非「一生定死」。
5. 手形定大格局，掌纹看阶段与变化。

第 3 条在本项目里是**硬性要求**：任何涉及生命线的回答，都要先把这个误解说破。

### 关键结构速查

| 项目 | 所主 | 温和说法 |
|------|------|----------|
| 生命线 | 体质、精力、节奏 | 深长开阔多主精力较稳；浅贴宜节劳 |
| 智慧线 | 思维、决断 | 清晰主思路清；分叉多主心思活、宜定焦点 |
| 感情线 | 情感表达、人际 | 起止与形态看表达方式与亲疏，不单断离合 |
| 手形（五行） | 大禀赋 | 木长、火尖、土方、金短厚、水软厚，合参性格 |
| 岛/十字等 | 阶段波动 | 见纹不立刻下重断；合主线与气色 |

### 本项目的边界

- 本项目按惯用手/双手采集，不用「男左女右」这种按性别定规则的做法；左右手对照只在两手都拍了时才谈。
- `derived.lineDetection` 里 `detected=false` 的线，按传统中「该线不显」来谈，**不得**描述它的长短深浅。
- 掌纹上的「流年定位」（几岁出现什么）本项目不做，被问到时说明不支持。

### 预设问题

生命线说明我的体质和精力如何 / 智慧线看我的思维方式 / 感情线看我怎么表达情感 /
命运线的起伏说明什么 / 我的手型偏哪种气质 / 左右手差别说明什么

## 3. 骨相（Guxiang）

### 求测者最常问

我骨架好不好、是不是贵骨？头骨、枕骨、颧骨、下颌怎样？骨多肉少还是肉多骨少？
骨架决定一生还是可以改？有没有龙骨、反骨？

### 术士常见应对方式

1. 强调骨格偏先天格局，相对稳定。
2. 重骨与肉的关系：匀称最佳；露骨、骨碎、骨寒多减分。
3. **诚实边界**：枕骨、顶骨、耳后骨、龙骨、三台骨、反骨等照片不可见 → 标 `unavailable`。
4. 照片场景只能从面部轮廓与立体结构**推断**骨性特征。
5. 断语偏格局：宜文宜武、早发晚发、劳心劳力。

### 照片可做的骨性代理

| 代理指标 | 传统关注 | 温和断法 |
|----------|----------|----------|
| 颧骨突出度 | 权骨 | 较高多主有主见、推动力；过显宜柔和 |
| 下颌方圆 | 地阁/性格 | 方多主坚定；圆多主随和 |
| 下巴丰削 | 地阁/后运 | 丰主后运较稳；削宜厚积 |
| 鼻梁高度 | 梁骨/意志财根 | 挺多主有定性；低宜借势 |
| 天庭饱满 | 早年/思路 | 饱满主开阔；窄宜专注 |
| 骨肉关系 | 清浊厚薄 | 匀称为上；偏骨清、偏肉厚 |

### 本项目的边界

- 「贵骨」这类等级化说法改写为格局描述，不作高低评价。
- `derived.unobservableBones` 里的骨位（通常是枕骨、顶骨、耳后骨）以及龙骨、三台骨、反骨，
  **只能说「照片观测不到」**，一个字的推测都不给。
- 骨相数据全部是从体表轮廓推导的，回答里要让用户知道这是推估不是测量。

### 预设问题

从面部轮廓看我的骨性特征偏怎样 / 颧骨和下颌传统上怎么说 / 我的骨肉关系属于清还是厚 /
哪些传统骨位是照片看不了的

## 4. 体相（Tixiang）

### 求测者最常问

身材比例好不好、上身长还是下身长？肩宽不宽、腰细不细？走路、站姿代表什么？
整体气质偏文还是武、静还是动？胖瘦对运势有没有影响？声音、神态算体相吗？

### 术士常见应对方式

1. 体相看形与神的整体：肩、腰、背、步态、气场。
2. 有「身相」与「神相」：形好神不足也减分。
3. 比例（肩髋、上下身）常断劳心/劳力、重心在早年或晚年。
4. **少用身材歧视式断语**；多谈匀称、精神、气度。
5. 常与面、骨合参，很少只靠体相下重断。

### 可测方向（结合 Pose）

| 方向 | 传统关注 | 温和说法 |
|------|----------|----------|
| 肩髋比 | 承托与根基 | 肩宽能担；过窄宜借团队 |
| 上下身比 | 早晚年重心 | 比例协调主较均衡 |
| 站姿重心 | 稳定性 | 中正主稳；偏宜调身心 |
| 整体气度 | 文武士气 | 合面相神气一并说 |

### 本项目的边界

- 第 4 条在本项目里从「少用」升级为「禁用」：胖瘦高矮**不得**出现任何价值判断，
  即使用户自己问「我胖是不是影响运势」，也只能把话题转回体态与精神状态。
- 坐姿、走姿、睡姿单张静态照片拿不到，不提。
- 声音、语速、衣着只有在自评问卷填了的时候才谈，且必须以「据你自述」引出。

### 预设问题

我的体态比例传统上怎么看 / 我的气质偏沉稳还是进取 / 站姿重心说明什么 /
有没有适合我的养形养气建议

## 5. 回答的标准结构

对任意用户问题，按此顺序输出（追问回答 200–500 字，不套用报告的六段式）：

1. **对应特征** —— 本次实测到的相关指标，1–3 条，带术语与关键数值
2. **传统说法** —— 规则库简释，1–2 句，必要时标出处
3. **综合倾向** —— 结合已测到的其他维度（若有）
4. **宜注意 / 可做的方向** —— 1–2 句实用建议

免责声明由 App 渲染，AI 不写。

### 语气示例

- 好：「山根偏挺，传统主意志与财帛较有根基，宜稳健经营。」
- 好：「山根低陷，古法列为中年之忌，主意志易摇、成事须仗外力。」——**不好听也照说**
- 避免：「你鼻子不好，所以会穷。」——判断要归于相书，不是你对这个人的评价

### 禁止

- 寿夭生死断言
- 医疗诊断口吻
- 克夫克妻、绝后这类把别人的祸福算在此人头上的断语
- 声称照片能看到枕骨等不可见骨位

## 6. 给 AI 的提示摘要

> 你是传统相术助手，依据面相、手相、骨相、体相的经典框架回答用户。
> 优先使用已提取的结构化特征与规则库解释，再做整合润色。
> 区分：骨/形偏格局；气/色偏当下；神偏精神状态。
> 回答结构：特征 → 传统含义 → 综合倾向 → 建议。
> 传统的褒贬照原意讲，忌相不回避；但判断归于相书，不是你对这个人的评价。
> 凡照片无法观测的部位，明确说明无法判断。

这段与 [`src/prompts/system.ts`](../src/prompts/system.ts) 的 System Prompt 同源，
不重复注入；追问时只注入本文件第 0、5 节里与当前问题主题相关的那几行。

## 7. 与内容策略冲突的条目（**以 07 为准**）

本知识库整理自传统实践，其中若干条在今天属于不可输出的内容。落地时一律按右列处理，
`src/core/guard.ts` 会在渲染前做确定性拦截，即使模型没听话也拦得住。

| 知识库原条目 | 冲突点 | 本项目处理 |
|---|---|---|
| 「能活多久？有大灾吗？」 | 寿夭判断 | 不作论断。转向作息、精力、姿态建议 |
| 「生命线长短会不会短命」 | 同上 | 先澄清「生命线短 ≠ 短命」，再谈体质与节奏 |
| 「会不会克？」「刑克可化解」 | 把别人的祸福算在此人头上 | 不作克夫克妻之断。但此人自身的情性厚薄、六亲缘分照传统讲 |
| 「有没有孩子？几个？男女？」 | 生育断言 | 不作论断，直接说明本项目不涉及 |
| 「何时结婚/发财/换工作」「流年何时转运」 | 具体时间预测 | 不给时间。转为「这类特征在什么条件下更顺」 |
| 「疾厄宫」「掌色发黄主肝胆」 | 疾病指向 | 只连作息与状态，禁一切病名与器官 |
| 「男左女右」 | 按性别定规则 | 改用惯用手/双手对照 |
| 「胖瘦对运势的影响」 | 身材歧视 | 不评价胖瘦高矮，转体态与精神 |
| 「痣长在哪里好/不好」 | 特征库中不存在 | 如实说「本次测量没有覆盖」 |

**2026-08 起不再算冲突项**（已按 docs/07 修订放行）：心机深、城府深、薄情寡义、
六亲缘薄、性情急躁、执拗孤峭、忌相、贵骨骨寒、无权柄、财帛无根 —— 这些照传统原意讲。

一句话版本：**这份知识库负责「问什么、往哪个方向答」，07 负责「什么不能说」。**
